应用监控录入

Google Play 填包名；App Store 填 Bundle ID 或 App ID。编辑时主标识保持只读。

当前：新增模式
编辑模式下不支持直接修改商店与应用主标识，如需变更请删除后重新创建。

厂商监控录入

支持厂商名、可选主页 URL，并可自动把新游加入应用监控。

当前：新增模式
编辑模式下不建议变更商店类型；如需切换商店，请删除后重新创建。

任务执行

可手动触发一条完整链路：先监控应用，再发现厂商新游，最后投递飞书通知。
