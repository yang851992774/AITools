# React Study

一个基于 React + TypeScript + Vite + Tailwind CSS 的现代化 React 学习项目。

## 技术栈

- **React 18** - UI 框架
- **TypeScript** - 类型安全
- **Vite** - 构建工具
- **Tailwind CSS** - 工具类 CSS 框架

## 开始使用

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 预览生产构建

```bash
npm run preview
```
****
## 项目结构

```
react-study/
├── src/
│   ├── App.tsx          # 主应用组件
│   ├── main.tsx         # 应用入口
│   └── index.css        # 全局样式
├── index.html           # HTML 模板
├── package.json         # 项目配置
├── tsconfig.json        # TypeScript 配置
├── vite.config.ts       # Vite 配置
└── tailwind.config.js   # Tailwind 配置
```

## 开发规范

- 使用函数式组件和声明式编程模式
- 优先使用命名导出
- 使用 TypeScript 接口而非类型别名
- 使用 Tailwind CSS 进行样式设计
- 采用移动端优先的响应式设计
